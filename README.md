# AI Engineering Knowledge

A structured, practical knowledge base on modern AI engineering, written for software engineers who are learning the field.

## Objectives

- Build a clear, technically accurate understanding of how LLM-based systems work.
- Explain concepts the way one engineer would explain them to another.
- Stay generic and reusable: useful for learning, design discussions and day-to-day engineering.

## Knowledge Areas

| # | Area | What it covers |
|---|------|----------------|
| 1 | [LLM Fundamentals](01-llm-fundamentals/01-llm-fundamentals.md) | How LLMs work, tokens, context, sampling, prompting |
| 2 | [Embeddings and RAG](02-embeddings-and-rag/01-embeddings-and-vector-databases.md) | Embeddings, vector search, RAG pipelines and optimization |
| 3 | [AI Agents](03-ai-agents/01-ai-agents-and-agentic-systems.md) | Agents, tool calling, MCP, orchestration |

| 6 | [AI Engineering](06-ai-engineering/01-model-training-and-fine-tuning.md) | Fine-tuning, evaluation, production concerns, coding assistants |

## How It Is Organized

- Each area is a folder with a small number of numbered topic files.
- Every concept has one primary location. Other files link to it instead of repeating it.

## How to Navigate

Areas build on each other, so reading in order works well. Each file is also written to be understood on its own, with links to related concepts.
